# TODO LIST - simple react native exercise

This is mobile App for adding and managing todo list using React native and Expo.

## Used libraries:

For building this App was used following tools and libraries.

- **Framework:**`[Expo](https://expo.dev/) (with template: `blank`)`

- **UI library:**`react-native-paper`

- **Navigation / SafeArea:**`react-native-safe-area-context`

## Setup:

1. **To install dependencies run in terminal:** `npm install`
2. **To start this Application run in terminal:** `npx expo start`
